# SLMassari.github.io

**This repository is now an archive.** The live site is at
**<https://samuelmassari.com>**.

## What's here

| Path | Description |
| --- | --- |
| `archive/` | The original portfolio site (2019–2026), preserved verbatim — see [`archive/README.md`](archive/README.md) |
| `LICENSE` | MIT license covering the archived Start Bootstrap *Freelancer* theme |

The old site was a single-page personal portfolio covering software engineering work,
skills and side projects. It has been replaced by a site for **engineering consulting**:
organizational reviews, targeted improvements, leadership coaching, and engineering
management mentorship.

## The new site

| | |
| --- | --- |
| Live site | <https://samuelmassari.com> |
| Source | [`SLMassari/samuelmassari.com`](https://github.com/SLMassari/samuelmassari.com) |

The new site is a TanStack Start + React + Tailwind application, prerendered to static
HTML at build time and deployed to GitHub Pages by GitHub Actions on every push to
`main`.

## Notes on this repository

- `archive/` is published verbatim by GitHub Pages (see `.nojekyll`), so the historical
  site remains browsable at <https://slmassari.github.io/archive/>.
- The original `CNAME` file was removed when the `samuelmassari.com` custom domain moved
  to the new repository. GitHub Pages allows only one repository to serve a given custom
  domain.
- Nothing in `archive/` is maintained. Changes are out of scope; it exists for historical
  reference.
